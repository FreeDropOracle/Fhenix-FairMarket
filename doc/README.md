# Production Readiness Reference

This folder tracks the execution plan for taking Fhenix-FairMarket from the
current merged milestone state to a fully operational Sepolia release.

Files:

- `vault-ui-direction.md`
  Primary UI direction for the product redesign using the "digital vault"
  concept and beginner-first simplification.
- `vault-ui-design-lock.md`
  Approved mockup mapping and frozen visual rules for the redesign before code
  implementation.
- `vault-ui-implementation-plan.md`
  Practical frontend implementation order mapped to the current page files and
  redesign priorities.
- `production-readiness-7-day-plan.md`
  Seven-day roadmap from merged code to operator-ready deployment.
- `day-1-main-cleanup-and-deployment-readiness.md`
  Detailed execution checklist for Day 1.
- `simplified-ui-architecture.md`
  Beginner-first UI structure that preserves the current site sections while
  reducing cognitive load.

Suggested usage:

1. Start with `vault-ui-direction.md` for the canonical UI direction.
2. Use `vault-ui-design-lock.md` for the approved page-level visual baseline.
3. Use `simplified-ui-architecture.md` for the structural UX simplification.
4. Use `vault-ui-implementation-plan.md` for the actual frontend execution
   order.
5. Start with `production-readiness-7-day-plan.md` for the overall sequence.
6. Execute `day-1-main-cleanup-and-deployment-readiness.md` step by step.
7. Add future Day 2-Day 7 detailed checklists in this folder as work continues.
